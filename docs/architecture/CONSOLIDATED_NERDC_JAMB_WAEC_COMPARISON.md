## Coverage disagreements summary

- **NERDC vs JAMB/WAEC**: NERDC SSS1/SSS2 topic lists omit several topics that JAMB and WAEC both list (sets, logic, sequences & series, matrices, mensuration, loci/construction, coordinate geometry detail, calculus, probability detail, financial maths, friction/vectors as standalone, energy-society applications, buffers, water, air, non-metals, metals, industry, pollution). - **CDG vs all sources**: The CDG covers the core families (algebra, trigonometry, calculus, statistics; mechanics, waves, optics, electricity, modern physics; atoms, bonding, mole, acids, redox, organic) but lacks many listed objectives at method level and lacks entire families (sets, logic, matrices, mensuration, projectile motion, SHM, water, air, non-metals, metals, polymers, industry).
