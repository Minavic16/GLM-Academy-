# Mathematics — Deduplicated Gap Register (Phase 19 triage)

Provenance: Phase 19 "Official JAMB Evidence Reconciliation and Mathematics
Gap Triage" (2026-10-17; baseline commit `765a292`). This register is the
detailed triage companion to the cross-subject
`DEDUPLICATED_IMPLEMENTATION_GAP_REGISTER.md` and to
`JAMB_MATHEMATICS_RECONCILIATION.md` (record-level evidence). It supersedes
the Mathematics rows of the cross-subject register for disposition detail;
no row of any existing register was deleted or overwritten.

Dedup rule: one row per requirement unit, regardless of how many source
documents evidence it. Sources merged per row are listed under
"duplicates/overlaps".

Status vocabulary (repository): Open | Blocked | Deferred (owner-documented).
Coverage classification: COVERED | PARTIALLY_COVERED | NOT_COVERED
(matrix vocabulary; scope-and-depth rule — matching names is insufficient).
Evidence statuses are kept separate per dimension and never merged:
JAMB-OFFICIAL (content-checked Phase 18/19) | NERDC-SS1/SS2-OFFICIAL
(content-checked Phase 16) | SECONDARY (Syllabus NG mirrors — never
authoritative) | WAEC-OFFICIAL (outstanding) | NERDC-SSS3 (unavailable).

Dispositions: `NO_ACTION_COVERED` | `DOCUMENTATION_CORRECTION` |
`OWNER_SCOPE_DECISION` | `IMPLEMENTATION_CANDIDATE` |
`EVIDENCE_RETRIEVAL_REQUIRED` | `UNRESOLVED`.

Priority criteria (reproducible):
- **P1** — officially confirmed JAMB requirement with no adequate
  implementation and no blocking dependency: prime candidate for the first
  implementation wave.
- **P2** — officially confirmed JAMB requirement partially implemented
  (depth extension of an existing family): subsequent waves.
- **P3** — requirement not established by the official JAMB document
  (WAEC-secondary-only or NERDC-only) or under a standing documented
  deferral: decide later / after WAEC retrieval.

No implementation may proceed without owner authorization (Phase 15/16/17
scope rules). Board verification remains governed by CI-24.
